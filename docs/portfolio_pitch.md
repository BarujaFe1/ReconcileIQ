# ReconcileIQ — Portfolio Pitch

## One-liner

Reconciliation intelligence that turns messy marketplace/e-commerce ledgers into an auditable matching, confidence and exception-resolution workflow.

## Interview talking points

1. Exact vs fuzzy record linkage and when each is safe
2. Precision vs recall trade-offs in payment matching
3. Confidence scores as operational decision support, not automation
4. Append-only audit trails for financial exception handling
5. Why fee anomalies are a first-class leakage signal

## Demo path (3 minutes)

1. Open Financial Leakage Board with demo seed
2. Inspect Matching Workbench side-by-side pairs
3. Sort Exception Inbox by severity/impact
4. Resolve one exception and show audit trail update
5. Explain fuzzy match reasons and remaining limitations
